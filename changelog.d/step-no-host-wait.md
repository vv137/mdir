### Changed

- **The work of a step on the GPU goes to the device as CUDA graphs** (#60). `[execution] step_graph = "SPANS"`, the new default on the GPU, records the launches, transforms of cuFFT, sets of memory and flag events that the host issues between two host boundaries (a wait, a copy, a change of stream), and issues a span that repeats, kernels, grids and argument bytes alike, as the CUDA graph made at its second recording. The device runs the same kernels in the same order with the same arguments, so results are bitwise those of `"LAUNCH"`, which keeps the previous submission. `"GRAPH"` (TOWERS, D439) records spans in its other steps. The log ends with the counts of the spans; `MDRT_SPANS=0` turns them off. A simulation of the Python interface refuses `"SPANS"`. D[step-no-host-wait].
