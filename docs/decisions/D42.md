# D42

Recorded 2026-09-29.

**The minimum image [[AllenTildesley2017]](../references.md#allentildesley2017) is found with a multiplication** by one over the edge lengths, which is computed once. The number of images is a whole number, so the displacement of a pair differs from that of a division only if the pair is within rounding of half an edge apart, which is beyond every cutoff.
