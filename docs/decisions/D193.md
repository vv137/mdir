Assignments validate and copy before advancing versions. Enabled Python requires NumPy >=1.23, checked with the selected interpreter at configuration and again at import; CLI builds need neither Python nor NumPy. CPU DLPack is copied without gradients; device views and leases remain a later gate. Native storage, compiler physics, control keys, formats and overwrite behavior are unchanged. Bitwise native-value round trips and CPU/GPU mixed/double IR parity accompany the boundary. See [python-arrays.md](../python-arrays.md).
