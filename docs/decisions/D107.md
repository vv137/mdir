# D107

Recorded 2026-10-01.

**A build of a neighbor structure on a device gives a position that is not a number no cell and no place, counts it, and the run then stops with a word.** A position that is NaN (or beyond 10¹⁰⁰) sent every particle into one bin of the build, whose sort of a bin is one thread: a run that had failed (D106; a time step too long; a bad contact) spun at 100% of the device and 150 W instead of stopping, with either structure. The kernel that bins the particles now skips such a position and adds it to a count that the build returns with its sizes (the fifth size of the groups, a second result of the matrix); a place left empty is skipped by the search of the matrix. The lowering reads the count after the build, one load from the copy it makes anyway, and `mdrtStopNotNumbers` prints the count and exits. A kernel before the build was tried first and could not be: the build is lowered inside a region not yet attached, where `gpu.launch` cannot be sunk its constants. The test of each template poisons a particle; `not-numbers-gpu.test` runs ff19SB with a time step of 0.5 ps under both structures. *Amended (#425): the blow-up of that run did not always reach a NaN or 1e100 within its 100 steps (about 5 runs of the matrix in 100 stayed finite, near 1e17 Å, and ended without the stop), so the test now starts the first particle with a velocity of 1e110 and a step of 0.002 ps, which puts it about 4e108 Å away at the first step whatever the forces; an input that is not a number from the start is refused by the topology before any build.*
