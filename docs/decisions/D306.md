# D306

Recorded 2026-10-21.

**A linear transform is an execution primitive with its adjoint and pairing declared in the IR.** The first kind, `md_exec.linear_transform` with `kind("fft3d")`, takes an unnormalized real-to-half-complex forward FFT or its unnormalized backward adjoint. The verifier requires the opposite `adjoint` direction and `pairing("real_hermitian_half")`, validates known buffer lengths and grid overflow, and records the input and output memory effects. Pocketfft and cuFFT remain the lowerings; this addition changes no reciprocal-sum kernel, control-file key, or output. NumPy DFT and adjoint-identity tests use odd and even last-axis grids in mixed and double precision on the CPU and GPU. The semantic transform, reciprocal composition, and differentiated chain remain #452. Issue #480.
