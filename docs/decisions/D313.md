# D313

Recorded 2026-10-21.

**`md_dist.migrate` creates a new ownership epoch from current owned positions, and `md_dist.redistribute` carries a complete owned field to that epoch by global particle identity.** #494, first slice of #38. A destination's rows are in identity order; empty domains participate; the in-process CPU runtime verifies a bijection of identities and stages new buffers without modifying the old epoch. The verifier requires the field's old layout to be the exact source of the migration and rejects old-epoch use with the new layout. An optional image wraps three-component positions in the migration cell. The operations compose a partition and a per-field gather; they do not yet implement a loop-carried state, collective skin/rebuild branch, production trajectory, MPI/GPU transport, or `[distribute]` control keys. Moving-snapshot LJ and EAM comparisons with one-domain oracles test the primitives in double and mixed precision.
