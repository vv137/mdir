# D320

Recorded 2026-10-22.

**A tiled reciprocal sum allocates bins and no unused spreading bricks; its order-4 f32 weighted gathering is selected for tiles even without bricks, and for a non-tiled sum with bricks.** #517, after D315. A non-tiled, non-fixed-order f32 sum retains bricks for B-splines of order 4 and for the prolate window, where the spreading consumes them. Fixed-order sums retain their fixed-point spreading, and f64 sums need no bricks. The scratch layout remains positional, with an i32 bin buffer distinguished from an f32 brick buffer by element type. A manually formed non-tiled B-spline sum without bricks retains floating-point atomic spreading and ordinary gathering. This removes one grid-sized allocation and its initial zeroing for each tiled grid shape without changing the tiled kernel or gathering arithmetic. *Validation*: storage and lowering IR tests cover tiled and non-tiled paths; the existing PME, LJ-PME, tiled-spreading, and prolate GPU tests pass in mixed and double. The independent three-OPC-water Ewald reference is −14.326815489 kcal/mol; GPU double is −14.3268390 (relative difference 1.6 × 10⁻⁶) and GPU mixed is −14.3268240 (5.9 × 10⁻⁷), below 3 × 10⁻⁶. A deterministic 200-step JAC GPU run produced a bitwise-identical final checkpoint to main. *Measured* (RTX 4090, STMV from the GROMACS topology, NPT 4 fs, mixed, groups, 1,000 steps): the peak device memory fell from 2,567 to 2,521 MiB at one replica and from 22,789 to 22,283 MiB at eleven replicas (11.74 million atoms); the steady step times were 4.063 to 4.071 and 57.038 to 57.100 ms, respectively, one run of each. Twelve replicas still ran out of device memory during preparation. No control-file key or output format changes.
