Recorded 2026-10-22.

**Assigning a decision number also updates links to Markdown headings whose GitHub anchors contain its label.** #512. The assignment computes the old and new anchors for each tracked Markdown heading, including duplicate-heading suffixes, and changes local links and reference definitions to those headings before replacing `D[<label>]` in tracked files. The strict and pending checks report broken decision-label anchors, so a numbering commit catches stale links even without the full suite. There is no control-file key, runtime behavior, or numerical result.
