# D70

Recorded 2026-09-30.

**The grid of particle mesh Ewald is accumulated in fixed point**, 64-bit integers at the scale 2⁴⁰ with integer atomics, on the host and on a device, so that the sum does not depend on the order of the threads (P6) [[LeGrand2013]](../references.md#legrand2013). *Amended by D84:* on a device the grid is in fixed point in the deterministic mode only; by default the charges are added with floating-point atomics in the type of the grid. The host keeps fixed point.
