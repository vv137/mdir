# D172

Recorded 2026-10-03.

**A checkpoint records what defined its run, and a run that takes it compares: `--continue` refuses a change of the physics or of the coupling and names it; a run that begins from another run's checkpoint evaluates its forces and the state of its barostat again when anything differs.** The fingerprint is a list of entries in `/parameters/mdir/fingerprint`, in three groups. *Physics*: every key of `[energy]`, `[pme]`, `[lj_pme]`, `[constraints]`, `[restraints]`, `[boundary]`, and `[free_energy]` as the control file writes it, in a canonical form; SHA-256 of the contents of the files that define the topology (Amber, GROMACS with its included files, CHARMM structure and parameters); of the masses; and of the reference of positional restraints. *Coupling*: every key of `[dynamics]` but `steps`, and of `[ensemble]`, `[thermostat]`, and `[barostat]`. *Execution*: `[execution]`, and `pairlist_distance`, `pruned_distance`, and `rebuild_interval` of `[energy]`, which decide how the forces are found and not what they are; these may change. `mdir run --continue` fails on a difference in the first two groups and prints each changed entry with its old and new value; a change of the target, the threads, or the precision is noted in the log, and the run continues (its bits then follow the new mode); a longer `steps` extends the run. A run whose `[input] checkpoint` is another run's takes its forces, its barostat state, and its thermostat chain only when physics and coupling match, which keeps a chain of runs bitwise; otherwise it notes what differs and evaluates the forces and the barostat state at its first step, and starts a new chain when `[thermostat]` or `[ensemble]` differ. Measured on the mixture of `thermostat.test`: the same physics written so that it counts as a change (the default `dispersion_correction` given) evaluates forces that are those of the checkpoint bit for bit, and the run arrives at the state of the run that did not stop, on the CPU and on a GPU in mixed precision; a stage of tri-alanine in water that drops the restraints of equilibration names `[[restraints]]` and their reference and evaluates its first forces. Without this, a stage of the standard pipeline that changes the Hamiltonian (production after NPT with restraints) began with one step of the forces of the stage before, and a continued run accepted a changed mass, cutoff, thermostat, or ensemble without a word (review of 2026-10-03). Entries are the written keys, not the resolved values: a key added with its default value counts as a change, and a default that a later MDIR changes does not; the release keeps defaults stable. The warning that the cell differs from the input is given only for another run's checkpoint.
