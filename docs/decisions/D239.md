# D239

Recorded 2026-10-09.

**A trajectory that holds the frames of a run without loss is a third trajectory format, H5MD 1.1 [[deBuyl2014]](../references.md#debuyl2014): `[output] trajectory = "x.h5md"` (by the extension `.h5md`, or `trajectory_format = "H5MD"`; `trajectory_precision = "DOUBLE"` or `"SINGLE"`, `trajectory_strings = "FIXED"` or `"VARIABLE"`) and `mdir.H5MDReporter(file, period, positions="f64", velocities=False, forces=False, strings="fixed")`; `mdir.read_h5md` reads it one frame at a time.** Issue #251, for the frame evaluator of M2b (#249). The writer sits behind the interface of DCD and XTC (D141), so backups, parts, the frame count of the checkpoint, and the cut and append of a continued run are those of D130 and D149; the host function of the frames hands it the buffer of the state before the conversion to Å and f32, so positions-only frames are written inside the parts of a run (D207). `/particles/all/position`, `box/edges` (time-dependent, `[3]` or `[3][3]` with the cell vectors in rows, `step` and `time` hard-linked to those of the positions), optional `velocity` and `force` (Python: a frame then ends a part and is written from the state), fixed `mass` and `species`, `/observables/tunables_version` (D213) and `/observables/potential_energy` (the reported potential energy, where every frame is a step of energy), in nm, ps, kJ/mol, g/mol, the numbers of the state, labeled by the units module, whose `unit` attributes are strings of fixed length as it gives them, or of variable length by the option `strings` (maintainer, on the pull request; `/parameters/mdir/strings` records the form, a continuation in the other form is refused, and [python-h5md.md](../python-h5md.md#strings) lists which readers were found to read which); rows in the order of the input and no `id`. One chunk per frame (or 64 KiB of frames), no compression, a flush per frame, and the earliest file format, so a killed run leaves a file that opens with the frames flushed. Only `.h5md` selects the format by extension: `.h5` is the checkpoints'. [python-h5md.md](../python-h5md.md).
