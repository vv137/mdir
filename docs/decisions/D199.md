# D199

Recorded 2026-10-06.

**Persistent simulations own the final object memory and unwind boundary.** Amends D196: section placement is superseded as the lifetime guarantee by contiguous allocation and validation of actual relocated ranges. The old MLIR transformer is removed; equivalent section assignment in the owned wrapper remains a locality hint only. A reserved contiguous object allocation is checked after relocation, including late ORC-generated functions. Executable sections must share an owned allocation, one unwind table must be contained in allocated data, each parsed FDE must describe bytes inside an executable section, and the executable bounding interval must be disjoint from all live objects. Registration is deferred until checks and permission finalization pass. ORC object removal and the memory-manager destructor deregister before storage release; a mapper guard forbids release while frames remain registered. Creation, continuation compilation, execution, and teardown share the runtime mutex. LLVM relocation and synthesis and libgcc frame indexing remain explicit dependency assumptions. No control-file keys or formats change. Deterministic negative boundary tests and seeded retained-engine tests cover lifetime failures; see jit-invariants.md for validation. Issue #89.
