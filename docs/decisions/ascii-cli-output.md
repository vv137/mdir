# D[ascii-cli-output]

Recorded at its merge.

**The text that the `mdir` tool prints to the terminal is ASCII only, with one spelling of units and symbols: the angstrom `Ang`, exponents with `^` (`Ang^-1`, `g/cm^3`), `+/-`, `us`, `x`, `deg`, `sqrt`, and Greek letters by name.** The maintainer's ruling of 2026-11-09 (#812). The summary of `mdir check`, the log of `mdir run` (which its log file copies), and the warnings and errors of the libraries that the tool reports printed `Å`, `g/cm³`, `±`, `µs`, `σ`, `√`, and `α, β, γ`, which some terminals, logs, and pipelines garble. The table of spellings is in [conventions.md](../conventions.md#units-and-symbols-in-printed-text). The angstrom is `Ang`, not `A`, which is the ampere; the case-sensitive code of the Unified Code for Units of Measure would be `Ao`, and `Ang` reads without it. Only text changes: no number, classification, or refusal. The files MDIR writes keep their text (the line of units of the files of columns, which a continued run compares with the file it extends, the manifest of a run, the JSON summaries, the cache of the skins, and the templates of control files), as do comments and the documentation; a change there is one of a file format and needs a ruling of its own. A string that is printed and also recorded in a file keeps its text for now: the reasons for the automatic choices of the neighbor structure and of the skins. The messages of `lib/Driver/Builder*.cpp` and `lib/Driver/Term*.cpp` follow in #813. `scripts/check-before-push.sh` refuses a string literal with a non-ASCII character in `tools/mdir/*.cpp` outside a comment.
