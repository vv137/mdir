# D205

Recorded 2026-10-06.

**The Python model takes the control file's Coulomb modifier as `System.coulomb_modifier`.** Issue #127, found while preparing the Python ala3 example (#82). `CoulombModifier.None_` (the default, as `[energy] coulomb_modifier` defaults to `NONE`) or `CoulombModifier.PotentialShift` sets `Control::pmeShift`, the real-space Coulomb term of PME shifted to zero at the cutoff; as in the control file it is for PME only, and a model with cutoff electrostatics and the shift is refused with `InputError`. `System.truncation` stays the Lennard-Jones modifier. *Evidence.* On the dipeptide in water with PME, SHAKE, and SETTLE, deterministic: with the shift, the state of a Python simulation at step 10 equals that of `mdir run` with `coulomb_modifier = "POTENTIAL_SHIFT"` to the bit (positions, velocities, forces) in double precision on the CPU, and the rows to every printed digit on the CPU and a GPU; on a GPU in double precision the state differs in its last bits (3e-16 nm, 6e-12 kJ/mol/nm), exactly as much as without the shift, and in mixed precision the rows agree within 8e-9 (CPU) and 7e-8 (GPU): the differences of PME between the two front ends that #105 records, to which the shift adds none. The shift changes the potential by 0.10 kJ/mol. See [python-model.md](../python-model.md).
