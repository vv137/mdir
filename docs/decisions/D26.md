# D26

Recorded 2026-09-29.

**Checkpoints are written as H5MD [[deBuyl2014]](../references.md#debuyl2014), in 64-bit floating point.** A checkpoint holds positions and velocities, together with everything else an exact restart needs. H5MD is an HDF5-based format with standard places for positions, velocities, periodic images, particle IDs, and the box, and it allows application-specific groups. *Amended by D40: with velocity Verlet a checkpoint holds the forces.*
