# D128

Recorded 2026-10-02.

**An opt-in analytic projection handles isolated one-bond constraint groups.** `constraints.analytic_bonds = true` evaluates the rationalized near root along the old bond, checks the original squared-distance residual, and otherwise uses the existing six Newton iterations. The mass-weighted position impulse, RATTLE projection, periodic image and virial follow the existing path. It defaults to `false`; no iteration or precision is removed from larger groups or waters. CPU invariant tests cover equal and repartitioned masses, small corrections, periodic images, a near-tangent predictor, and the backward-root fallback. Driver tests compare energies, virials and bonds on CPU and GPU. On a Threadripper PRO 3995WX, one CPU thread, double precision, 1,728 noninteracting diatomics at 2 fs over 5,000 steps, three alternating comparisons gave median complete MD-stage times 0.413 ms/step (Newton) and 0.252 (analytic), 1.64×. The small mixed-precision RTX 3090 run gave 0.043 ms/step for both, at printed resolution. The real JAC protein/water system (23,558 atoms, 10,000 steps, three alternating repeats on an otherwise idle GPU) gave 0.211 ms/step for both. This favorable synthetic CPU result is not a protein/water speedup claim. See `scripts/benchmarks/constraints/README.md` for the benchmark procedure and limits. The supplied Schur-update experiment stays standalone: the current one-to-three-constraint groups expose no useful dense Schur work.
