# D185

Recorded 2026-10-04.

**Singular points use explicit reference conventions, without inventing finite derivatives.** `abs(0)` takes the nonnegative branch, min/max ties the second operand, and select differentiates its selected value without a condition tangent. Floor/ceil, integer conversions, step/delta, and discrete lookups are piecewise zero even at jumps. Continuous table endpoints are included with their first/last polynomial derivative; strictly outside, both value and derivative are zero, and periodic tables wrap to a half-open interval. An active square root at zero and coincident radial geometry may be nonfinite; an inactive square root is a proved zero without division. Central differences across jumps can disagree with the chosen branch and must report failure. Direct tests cover ties, active/inactive square roots, and coincident radial geometry. This documents the implemented arithmetic rather than changing the physics, part 4 of #15.
