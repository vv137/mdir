# D184

Recorded 2026-10-04.

**Requested derivatives can be checked against central differences of energy at an evaluation's actual inputs.** `--md-check-derivatives` checks every particle/Cartesian force component, each requested scalar parameter derivative, and the three stretches plus three upper-triangular shears of an explicit orthorhombic/restricted-triclinic cell, straining coordinates and cell together. A perturbation uses a fresh buffer, immutable after import, and exports it before freeing it so storage does not recycle it. CPU f64 is required; narrowing or device storage fails before lowering. Default step $10^{-5}$, absolute tolerance $10^{-6}$, relative tolerance $10^{-4}$; nonfinite comparisons fail. A runtime failure prints values and tolerances to stderr before aborting. Tests include a pair across a periodic boundary, seeds 15 and 161 for custom expressions, deliberately wrong forces, Lennard-Jones, bonds/angles/dihedrals, tables, and generalized Born. It is a diagnostic compiler pass for small configurations, not a production driver command. This is part 3 of issue #15 after D183; unconstrained cell orientations and GPU checks are not supported by this checker.
