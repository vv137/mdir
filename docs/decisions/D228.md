# D228

Recorded 2026-10-08.

**The Python interface is the package `mdir`, a pip wheel for CPython 3.10–3.13 on manylinux_2_28 (x86-64) built by scikit-build-core from `pyproject.toml`, whose version is read from `project(mdir VERSION ...)`; the extension `mdir._core` finds its runtime (`mdir/lib`) and libdevice (`mdir/cuda`) beside itself, HDF5 comes grafted by auditwheel, cuFFT and ptxas from NVIDIA's wheels `nvidia-cufft` and `nvidia-cuda-nvcc` through the extra `mdir[cuda]`, and the `mdir` command stays out of the wheel.** Issue #133, M2a item 7; the maintainer's decisions on PR #190. `mdir/__init__.py` imports the names of `mdir._core` and names their types `mdir.X`; the build tree has the same layout in `python/mdir`. The runtime is searched in `lib` beside the extension before the directories above it; without `CUDA_ROOT`, `CUDA_HOME`, `CUDA_PATH`, libdevice in `cuda` beside the extension or in `../share/mdir/cuda` (D177) before the build's toolkit; `libmdrt_cuda.so` takes cuFFT through the RPATH `$ORIGIN/../../nvidia/cu13/lib`, else from the system, and a GPU program without it fails with a `CompileError` that names the extra. ptxas is taken from a toolkit that `CUDA_ROOT` names, else from NVIDIA's `nvidia-cuda-nvcc` wheel beside the package (`nvidia/cu13/bin`), which the extra brings (`>=13.0,<14`: any ptxas of CUDA 13 assembles the PTX), else from `PATH`; without one the driver compiles the PTX, 34 s more over the first run of the ala3 tutorial. An environment with the extra holds 964 MB, 644 MB of it NVIDIA's (about 320 MB of that for ptxas). The wheel carries libdevice and the CUDA EULA (Attachment A, as D177) and the notices of MDIR, HDF5, and pybind11, but not cuFFT (287 MB; its wheel alone 214 MB, beyond PyPI's default limit of 100 MB): an MDIR wheel is 78 MB. The CLI is left out because it and the extension each link LLVM/MLIR statically. `packaging/Dockerfile.manylinux` builds the four wheels (target `wheels`, libstdc++ static, `auditwheel repair --exclude libcuda.so.1 --exclude libcufft.so.12`); `scripts/release/check-wheel.sh` checks them; `prepare.sh` sets the ala3 example's `mdir[cuda]==X.Y.Z`. Validated in clean environments of each version outside the trees: the CPU tutorial equal to the bit to the build tree's; GPU tutorial, mixed and double; single points equal to the bit except GPU mixed, which differs by 9.3e-7 of the energy through libdevice 13.0 against 13.4; NumPy 1.23.5; AlmaLinux 8 (glibc 2.28) without a GPU and with the driver only; the rates of `mdir run` on five systems of the Amber suite ([python-package.md](../python-package.md)).
