# D224

Recorded 2026-10-07.

**`mdir.compile` builds a program and sets up its pipeline without running it; `Program.lowered_ir` lowers on its first read.** Issue #151. Amends D192, under which `compile` validated and lowered, NVPTX code generation included on a GPU, for `lowered_ir` alone: a `Simulation` builds and lowers a program of segments of its own (D211) and never used that lowering, so every stage of a Python simulation lowered twice, the first time with the GIL held. `compiler::plan` builds, refuses a GPU program in a build without CUDA, asks for the GPU options (NVML, no CUDA context, so a process may still fork after `compile`, D214), and gives the pipeline text; `compiler::lowerToText` lowers a planned program in a context of its own; `compiler::lower` and `compiler::compile` are the two in sequence and are unchanged. `lowered_ir` lowers the IR captured at compilation with the GIL released, under a mutex, so that threads reading it at once share one lowering, and keeps the text. Errors of the inputs, of the build, and of the GPU options are still raised by `compile`; an error that only the MLIR pipeline finds is raised by `Simulation(program)` or by the read of `lowered_ir`. Not chosen: letting the simulation take the module that `compile` lowers, since the program of segments differs in text from the program of `compile`, whose `ir` is the CLI's (`mdir emit`) by D192's parity, and building the program of segments in `compile` would change `Program.ir`. *Evidence.* In the deterministic mode the Python ala3 example (`--steps-scale 0.01`) gives the minimized positions, the three energy files, and the DCD of `main` to the bit on the CPU (one and eight threads) and a GPU, in mixed and double precision. On one RTX 3090 in mixed precision, `mdir.compile` takes 0.3 s instead of 3.5, 5.4, 9.2, and 8.4 s for the four stages, and the example 62.4 s instead of 85.3 s. The Python tests of the suite (79 files) take 205 s instead of 211 s of wall time, bound by `python-memory-gpu.test`, and 2,316 s instead of 2,698 s summed over the files. `python-compile-lazy.test` and its GPU variant check that `compile` stores no GPU module in an empty compile cache and that four threads reading `lowered_ir` at once get one text. See [python-compile.md](../python-compile.md).
