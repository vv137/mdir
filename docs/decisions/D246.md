# D246

Recorded 2026-10-11.

**The Python model has `[pme] influence` and `[constraints] analytic_bonds` as `System.pme_influence` (`PMEInfluence.SPME`, the default, or `Optimal`) and `System.analytic_bonds`, and `System.pme_order` takes 6 and 8 as the control file does.** Issue #279, from the inventory of #270 ([python-model.md](../python-model.md#the-influence-function-and-the-order-of-pme-and-the-analytic-bonds)). The Amber suite's script sets the optimal influence function (D134) and may set the analytic bonds, and the Python model had no field for either, so a Python run could not compute the suite's model exactly; the order of the splines was a field that took 4 alone. The fields set what the reader of the control file sets; another order is refused with its words, and the fingerprint has the two keys when the fields were set. *Validation* (`python-pme-fields.test`, `-gpu.test`): the dipeptide in water with SHAKE and SETTLE at 2 fs in the deterministic mode, the optimal influence function, the analytic bonds, the orders 6 and 8, and the suite's two settings together, on the CPU and a GPU, in double and mixed precision: the potential of step 0 within 4.7e-7 kcal/mol of the row of `mdir run` (6 decimals), 20 steps equal to its checkpoint to the bit, its fingerprint, and each setting changes the run. | Decided
