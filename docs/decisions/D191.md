# D191

Recorded 2026-10-04.

**The first M2 implementation supplies a native value model and shares preparation with file input.** Owned Amber, GROMACS and CHARMM loading returns topology, positions, optional velocities, cell and source contents without drawing velocities or initializing CUDA. Physics and initial state are separate copies in MD units; typed integrator, ensemble and execution options convert once into the driver representation. Shapes, finite values and identities are checked before constraint resolution indexes arrays. Both front ends use the same prepared system and IR builder. The documented initial subset includes imported classical terms, SHAKE/SETTLE, virtual sites, cutoff/PME electrostatics, basic custom pairs/tuples, minimization, velocity Verlet/leapfrog and NVE/V-rescale NVT/isotropic cell-rescale NPT, CPU/GPU mixed/double. Other features are refused with typed input/unsupported errors. CHARMM takes an explicit cell and shares the symmetric-frame rotation with the CLI. Public framework differentiation is future work: keep parameter/state evaluation apart from simulation ownership, and add explicit derivative contracts rather than treating DLPack as an autograd connection. Native parity and analytic unit-conversion tests accompany the model. No control keys or checkpoint/output formats change; Python bindings, compile ownership and stale tracking follow in the next M2 PR. See [python-model.md](../python-model.md).
