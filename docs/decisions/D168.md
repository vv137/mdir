# D168

Recorded 2026-10-03.

**An optional `[output].manifest` records execution provenance as versioned JSON Lines.** U5: a start event records the build, input SHA-256 hashes and sizes, resolved seed, trajectory format, neighbor kinds, buffer precision and PME parameters, device identity and versions, warnings, output paths, step range, part, and UTC time; an end event records completion or a checkpoint stop and elapsed seconds. History appends on continuation, including a retry before its first checkpoint; `--no-append` selects the part file, and fresh runs use the existing numbered backups. A missing end event does not claim completion. Hashes include GROMACS includes actually opened. No new checkpoint fields or simulation semantics; no implicit manifest and no restart compatibility enforcement. The format and lifecycle are specified in [driver.md](../driver.md), Section 2.8.
