# D102

Recorded 2026-10-01.

**The gathering of PME of order 4 on a device takes the places of the particles from the weights.** The kernel of the weights (D85) stores, beside the first points and the weights along each edge, the fraction of each particle along it (18 values a particle, from 15); the gathering reads the first points and the fractions, computes the splines and their slopes again in the type of the grid, and numbers the points of the grid in i32. It no longer computes in f64 the place of each particle, four times (a thread for each point along z), nor addresses the grid in 64 bits. The fractions are the f32 values that it computed itself, by the same code, so the splines and the forces are those it gave; reading the 27 splines and slopes instead was slower (155 µs against 130, 2026-10-01). On Cellulose the gathering takes 90 µs a step, from 133, and the weights 55, from 47: the device 3128 µs a step, from 3163 (RTX 3090). *Amended by D109:* the places are six values a particle, the first points and the fractions; the gathering reads components 0 to 2 and 3 to 5.
