# D248

Recorded 2026-10-11.

**Where the Python model and the control file had different defaults for one setting, the Python model takes the control file's: a plain cutoff, `switch_distance` and `pairlist_distance` from the cutoff, the motion of the center of mass removed with the thermostat, and, for a state without velocities, those that `mdir run` draws; a system given to both front ends with nothing beyond its inputs is one model, to the bit.** Issue #281, the maintainer's decision on the inventory of #270 ([python-model.md](../python-model.md#the-defaults-are-those-of-the-control-file)); a breaking change of the Python API, with the list and what restores the old model under **Changed** in the changelog. Before: `Truncation.Switch` from 1.0 nm, which `mdir run` cannot state with a topology and which turned the default correction for the dispersion off with a warning (D222); a pairlist distance of 1.35 nm whatever the cutoff; `com_period = 0`; and a state without velocities at rest. Now `System.truncation` is `Truncation.None_`; `System.switch_distance` and `System.pairlist_distance` are not set until they are, and follow the cutoff as absent keys do (the cutoff; 1.5 Å beyond it, computed in Å so that both front ends hold one double), `None` restoring that; `Ensemble.com_period` is `None`, which hands the control the absent key (with a thermostat its interval, without one never); and `mdir.compile` gives an `InitialState` without velocities those of `assignVelocities` at `Ensemble.temperature` with `Ensemble.seed`, as `mdir run` does when its coordinates give none (a minimization begins at rest in both). At rest stays expressible: velocities that are given are kept, zeros among them. The fingerprint writes an entry for a setting that was given; it also no longer takes the default cutoff, 1.2 nm, for different from 12 Å. Amends the list of D223 in python-checkpoints.md. *Validation* (`python-defaults*.test`): the dipeptide in water with no setting but the files, the ensemble (NVE, NVT, NPT), the boundary, and the deterministic mode: the energies of step 0 within 4.7e-7 kcal/mol of the row of `mdir run` (6 decimals), and positions, velocities, forces, and the cell after 20 steps equal to its checkpoint to the bit, with its fingerprint, on the CPU and a GPU, in double and mixed precision. The tests that relied on an old default state it; none got new numbers for a changed default. | Decided
