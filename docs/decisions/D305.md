**The two-program staged-PaiNN GPU test pins its independent JAX reference to the CPU backend and compares energies within 0.013 kJ/mol for its fixed synthetic weights and water box.** #486. The test evaluates MDIR on a GPU in double precision and checks each model's energy, restoration of the first model after the second is released, and separation of the two weights. JAX's f32 composition of the same second model is 1291.753784 kJ/mol on the CPU and 1291.761261 on an RTX 4090; leaving its backend implicit made the old 0.008368 kJ/mol bound intermittent while MDIR stayed 1291.764984. With the original f32 weights promoted to f64 in an otherwise identical CPU JAX composition, the value is 1291.754766; MDIR differs by 0.010218, consistent with a fixed-order f32 body error. The new bound is about $10^{-5}$ of the smaller model's energy, as in the independent batched-stage composition check, and is far below the 91,413 kJ/mol separation of the weights. No production lowering or control-file key changes.
