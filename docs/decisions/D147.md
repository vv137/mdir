# D147

Recorded 2026-10-03.

**The standard pipeline is available as kinds of `mdir template`** (2026-10-03, U9). `minimize`, `nvt`, `npt`, and `production` print the four control files of `examples/ala3`, with `system.prmtop` and `system.inpcrd` in place of the example inputs. Their settings and checkpoint chain are embedded from the example files at build time, with those files tracked as configure dependencies: there is one source of the protocol, and a binary needs no source checkout to print it. Before, a researcher had to copy and locate the example files; now each stage can be printed by the driver and edited for the system. These are named stages, with no new command or aliases; `md` and `amber` remain the reference templates. The output names, lengths, GPU mixed precision, and HDF5 requirement are those of the example, stated in the templates and the guide; the input is never tailored silently to a machine or system. `pipeline-templates.test` checks the printed settings and reads all four with the example topology; `pipeline-run.test` shortens each to ten CPU steps, runs the checkpoint chain, checks the final step, and verifies that resubmission skips completed stages.
