# D332

Recorded 2026-10-22.

**`md_dist.covered` makes the skin test for a distributed halo a collective predicate over every owned identity in its ownership epoch.** #542, a first temporal-validity slice of #38. The verifier requires the halo's exact reference positions and cell and current positions in the same layout. The in-process CPU lowering compares plain displacements in the wrapped coordinate frame to half the reach-minus-cutoff skin, including empty domains. A periodic wrap invalidates coverage because halo images are explicit; the cell must stay unchanged. The predicate covers candidate membership only; current coordinate copies, a loop-carried halo, collective branching, and production driver integration remain in #38. No control-file key, output, or overwrite behavior changes. *Validation*: in an 8-cube, a nonwrapping 0.04 move is covered, whereas a 0.01-to-7.98 wrap is uncovered despite its 0.03 minimum-image move; the wrapped pair with a particle at 6.5 is 1.48 apart, inside cutoff 2.0. Single-mover x/y/z displacements of 0.25 and an exact half-skin displacement of 0.125 (reach 2.25, cutoff 2.0) are uncovered; 0.0625 is covered. Results match this analytic oracle exactly on 2 and 16 domains, including empty domains. Both lowering routes call the same f64 reference predicate, independent of the `md_exec` precision setting. The verifier rejects a wrong reference version, cell, ownership epoch, and nonpositive or too-large cutoffs. The final suite is recorded in the PR.
