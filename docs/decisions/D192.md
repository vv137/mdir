# D192

Recorded 2026-10-04.

**M2 exposes an optional Python lowering interface with owned, versioned inputs and immutable compiled IR.** pybind11 3.0.1 binds the D191 loaders and typed configuration. Collections return copies and reassignment advances input versions; programs retain those owners and reject stale use through `check_current()`. Compilation validates through the shared model and lowers through the CLI pipeline, returning semantic/lowered IR and a copied plan without loading runtimes, initializing CUDA execution or writing outputs. Imported topology is read-only. JIT/runtime ownership, tunable buffers, segments and wheel packaging remain M2 gates. No control keys, file formats or overwrite behavior change.
