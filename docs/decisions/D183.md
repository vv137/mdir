# D183

Recorded 2026-10-04.

**Scalar rules are dispatched by an op interface, with external models for arithmetic, math, vectors, and table lookup.** Every model declares differentiable and structural operands; tangent emission consults this declaration. A successful null tangent is a declared or proved zero; a missing rule fails. Activity recognizes modeled scalar operations rather than an entire dialect namespace. `--md-check-derivative-coverage` rejects any scalar operation in a potential without a rule or declared zero. Existing derivative arithmetic is preserved, and vector construction gains a component-wise derivative. This is part 2 of issue #15, following D182.
