# D249

Recorded 2026-10-11.

**The Python model selects the thermostat with the keys of the control file, and takes Brownian dynamics: `Ensemble.thermostat` (`ThermostatMethod.VRescale`, the default, `Langevin`, `NoseHoover`), `Ensemble.friction` (1/ps, needed by Langevin dynamics and refused otherwise), `Ensemble.chain_length` (3 by default, for a Nosé–Hoover chain), and `Integrator.method = IntegratorMethod.Brownian` with `Integrator.friction` under `EnsembleKind.NVT`; `Ensemble.coupling_period` is `None` until set, the control file without `interval`.** #278, from the inventory of #270: the Python model had stochastic velocity rescaling alone, implied by `Ensemble.kind`, and refused Brownian dynamics. `prepare` fills the control structure that the reader fills (`thermostatMethod`, `friction`, `chainLength`, the integrator), with the reader's refusals and words, `model` for the path; the builder and every program of a step are unchanged. The control file has no default method, so the model keeps the velocity rescaling that the kind implied. The two frictions stay two fields as they are two keys, of `[thermostat]` and of `[dynamics]`, so that one given for the other is refused as in the file. The default of `coupling_period` follows D248: under Langevin dynamics at constant volume the file has no period, and a kept default of 10 would be another program than the file without the key. The control file refuses a key by its presence and `prepare` sees values: `friction`, `coupling_period`, and `com_period` are `None` until set; `tau_t` and `chain_length` are refused where they are not their defaults. The set-up of the Nosé–Hoover chain (D163a) is `Output::setChain`, which `mdir run` and a simulation both call; a Python checkpoint holds the state of the chain, a continuation takes it, a stage of another thermostat begins it at rest with a warning (as D172 for `mdir run`), and a part that fails leaves it as it was. The fingerprint has `[thermostat] method` as the model's thermostat with `friction`, `chain_length`, and `interval`, and `[dynamics] friction`; `Program.plan["thermostat"]` and `["integrator"]`. Validated against `mdir run` to the bit in the deterministic mode (7 cases on the dipeptide in water, CPU and GPU, double and mixed, in parts and across a checkpoint in both directions, the energy file and the trajectory byte for byte, the state of the chain; [python-model.md](../python-model.md#the-thermostats-and-brownian-dynamics)). What the thermostats control at a finite time step (#268) is not touched.
