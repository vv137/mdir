**Unknown control keywords explain how to repair the input** (2026-10-03, U7). The same list of supported keys that validates a table supplies its diagnostic: the file, line, and table, a unique nearest spelling within two character insertions, deletions, or replacements, the supported keys, and a hint to use `mdir template md` or `mdir template amber`. Two edits include adjacent transpositions; the bound avoids unrelated suggestions, and a tie gives no preferred spelling. Before, `cutof` in `[energy]` only reported an unknown keyword; now it suggests `cutoff` and lists the alternatives. Inputs remain errors until the user corrects them, and numeric parameters in tables of terms and types remain valid. `test/Driver/keyword-hints.test` checks insertions, deletions, replacements, transpositions, table names, distant spellings, ties, and keys valid only in another table.
