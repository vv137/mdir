# D132

Recorded 2026-10-02.

**The checkpoint before is kept as `<checkpoint>.prev`.** Before the rename that replaces a checkpoint, `.prev` is made a hard link to it, so that the name of the checkpoint holds a complete state at every moment. Where the file system has no hard links, the checkpoint is renamed to `.prev` instead; if the run ends between the two renames, `--continue` finds `.prev` alone and refuses to begin the run anew, saying what to rename. An error in reading a checkpoint names `.prev`.
