# D62

Recorded 2026-09-29.

**MDIR has one form for each term of the potential and one meaning for each parameter**, which [conventions.md](../conventions.md) states: harmonic bonds and angles as $\tfrac12 k (x - x_0)^2$, periodic dihedrals as $k (1 + \cos(n\phi - \phi_0))$ with the IUPAC sign of the dihedral, Lennard-Jones as $4\varepsilon \big((\sigma / r)^{12} - (\sigma / r)^6\big)$ with $\sigma$ and $\varepsilon$ for each pair of types, Coulomb with the constant of CODATA 2018. Readers convert into these forms, and one library of the front end builds the kernels from them, whatever the format.
