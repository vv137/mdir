# D339

Recorded 2026-10-25.

**The `water-box.py` generator writes `.gro` residue numbers modulo 100,000, as it already writes atom numbers.** #550. Both identifiers remain in their five-column fields when more than 99,999 waters are generated. The topology still counts every molecule, and the coordinates and velocities remain unchanged. There is no control-file key, output destination, or overwrite change. *Validation*: the generated boundary rows and the complete 100,001-water file are checked against fixed-width fields and read by MDIR.
