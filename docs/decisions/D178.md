# D178

Recorded 2026-10-04.

**Tabulated functions may read their values from a text file.** `[[energy.function]]` accepts `values_file` and `shape` in place of inline `values`. The file contains finite decimal numbers separated by whitespace, with `#` comments; the last argument varies fastest, matching inline nested lists. `shape` is a list of one to three positive grid sizes and the file must contain exactly their product. Paths are relative to the control file. The existing ranges, continuous or discrete interpolation, and periodic endpoint checks apply. Files are inputs protected from output collisions and hashed in the manifest; continuation compares the loaded values and rejects changed grids. The file and inline forms emit identical IR, including an asymmetric 2×3 grid; independent natural/periodic spline and central-difference oracles pass on CPU/GPU in mixed/double, within $10^{-6}$ and $2\times10^{-5}$ of the largest force, respectively.
