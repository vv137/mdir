# D341

Recorded 2026-10-25.

**Bridge semantic FFT values to execution buffers with private storage for each result and each backward input.** #526, part of #452. `md.linear_transform` accepts matching f32/complex<f32> and f64/complex<f64> static rank-three tensors. The bridge packs the row-major Hermitian half-spectrum as adjacent real and imaginary scalars in a flat rank-one buffer, preserving the transform kind, direction, opposite adjoint, and Hermitian-weighted pairing. A backward call may overwrite its execution input, so the bridge owns a private copy and never mutates the semantic tensor. Forward and backward outputs are fresh values. One-shot bufferization and ownership-based deallocation establish host-buffer lifetimes before an optional device-placement pass allocates, stages through host buffers, and releases its two device buffers. Each host-device copy currently invokes the runtime-wide `finish()` and synchronizes both runtime streams. This host-boundary bridge is part of #526; device-resident composition with scoped dependencies remains #580 under #567. The current `md.reciprocal` route, control-file keys, file formats, and overwrite behavior are unchanged. Numerical validation is recorded in PR #563; #526 remains open.
