# D319

Recorded 2026-10-22.

**The pure semantic `md.linear_transform` describes an unnormalized three-dimensional real FFT over a static grid and its packed Hermitian half-spectrum as SSA tensor values.** The operation requires `tensor<K0xK1xK2xf64>` and `tensor<K0xK1x(K2/2+1)xcomplex<f64>>` in opposite directions, each grid extent from 2 through the 32-bit limit and checked products. Its `adjoint` must name the opposite direction and its `pairing` must be `real_hermitian_half`. `AdjointOpInterface` emits the opposite transform for the input cotangent; `--md-check-transposes` recognizes this structural operation. This is the semantic node for #452, following D306's execution transform, but it has no value-to-buffer bridge or differentiated reciprocal chain yet. The valid half-spectrum subspace is the image of a real grid; arbitrary complex values on zero and Nyquist planes are outside the contract. No control-file key, Python API, output, or performance path changes. Issue #502.
