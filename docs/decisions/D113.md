# D113

Recorded 2026-10-01.

**The host reads a flag of the device without waiting for the work issued after it, and the reciprocal sum goes before the test of the neighbor structure.** At each step the loop that moves the particles sets a flag where one has moved more than half the skin, and the host read it to decide whether to build the structure: a copy that waited for the stream, after which the device stood idle until the host had issued the next kernels. On JAC the device was idle 45 µs of a step of 249 (NVE, nsys) and 86 of 331 under NPT, with 1.5 waits for the stream a step. `mdrtFlagStart` now copies the flag into memory of the host that the runtime pins and records an event; `mdrtFlagFinish` waits for that event only, and the lowering puts it before the first op that uses the flag, not after the loop. A reciprocal sum between the test and the first loop that takes the structure moves before the test (it reads the positions only, and the test writes the structure; a sum on the second stream keeps the window of D87), so that the device computes it while the host waits. JAC (2000 steps, the second half): NVE 739 against 695 ns/day, NPT 600 against 522 (coupling every 10 steps); the waits for the stream fall to 0.5 a step, those of the builds, and the device is idle 31 µs a step in NVE. Cellulose, whose kernels are long, is unchanged (60.1 and 60.4 ns/day). `kernels.mlir` checks where the copy begins and where the host waits. *Amended 2026-10-02:* the sum moves before the test only if its operands, its scratch included, are defined before it: a run of one step with no energies allocated the scratch after the test, and the lowering left a use before its definition (`pme-gpu.test`). **Amended by D179.**
