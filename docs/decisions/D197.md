# D197

Recorded 2026-10-06.

**The host code of a program is compiled at LLVM's default level of code generation, by one machine that both front ends make (#90).** MLIR's `ExecutionEngine` compiles with the `TargetMachine` it is given, or with one at the default level that it makes itself; its `jitCodeGenOptLevel` option sets the level of a builder that it does not use, so the `Aggressive` that `mdir run` and the Python simulation asked for was never applied. `compiler::createHostMachine()` now makes the machine at `CodeGenOptLevel::Default`, and both pass it. *Evidence.* With the level chosen through the machine, on one RTX 3090 in mixed precision: JAC, Factor IX, and Cellulose (NVE) ran at 0.202, 0.590, and 2.701 ms per step at `Default` and 0.202, 0.591, and 2.702 at `Aggressive`; JAC on the CPU at 197 and 193 ms per step, within the noise of that run. `None` saved about 1.4 s of host compilation on the GPU but was 50% slower on the CPU. Run behavior and outputs are unchanged.
