# D63

Recorded 2026-09-29.

**The molecules that SETTLE constrains can be chosen.** From a GROMACS topology, those with `[ settles ]`; from an Amber topology, the residues named in `water_residues` of `[constraints]`, `["WAT"]` by default. A named residue that is not a rigid water of three sites is an error. `rigid_water = false` constrains the same water with SHAKE.
