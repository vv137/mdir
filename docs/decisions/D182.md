**Activity is a separate analysis shared by scalar derivatives, positional fields, sum weights, and parameter derivatives.** Active identifies a path from the variable, proven inactive permits a zero derivative, and unknown carries a reason and fails a required derivative. The proof follows operands and captured kernel values and distinguishes known function/kernel arguments from arguments of unknown regions. `--md-analyze-activity=argument=N` exposes the outcomes for testing and diagnosis. The implementation extracts D161's parameter analysis and applies its policy to positions and cell variables as well; it changes no generated arithmetic for supported inputs. Tests cover captures, intermediate fields, unknown ops, and the existing numerical scalar/tuple/position/parameter paths. Scalar rule interfaces and numerical checking follow as separate parts of issue #15.
