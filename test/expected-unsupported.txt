# The tests expected to be unsupported, by the lit feature that decides it
# (#608; docs/workflow.md, Validation). lit.cfg.py compares this list with
# what the features of a configuration leave unsupported, before the tests
# run (test/mdir_lit.py): on a run of the whole suite a difference is a
# warning, and with -Dexpected_unsupported=strict an error.
#
#   without <feature>: <test>   the test needs the feature (REQUIRES)
#   with <feature>: <test>      the feature makes it unsupported (UNSUPPORTED)
#   without <feature>: *        every test whose REQUIRES names the feature
#
# A test is expected to be unsupported when an entry for it holds. A test
# unsupported for a feature that has no entry here (torch, torchpme,
# openmm, h5py) is not expected: a full suite gives lit the interpreters
# that have those modules. test/Lit/expected-unsupported.test checks that
# each test listed under a feature names it, and that every test naming a
# feature with explicit entries is listed under it.
